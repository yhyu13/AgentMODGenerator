How many MiniMax calls per mod?

image-01 is ~0.025 CNY/image, min 512×512, max 9 images per request. SDV shop mods want many tiny icons. Click one.

A

Hero assets only (recommended)

~4–8 unique images: channel icon, letter background, catalog tile, 1–4 featured item icons. Rest reuse vanilla SDV sprites via EditData item IDs.

Cheap, fast, matches “TV shopping channel” without cloning 100 TVSN PNGs. Fail closed to _make_png() if the key is missing.

B

One sprite sheet, then slice

1–2 MiniMax calls for a grid (e.g. 8×8 cells). Post-process slices into 16×16 / 32×32 slots. Style is consistent; quality per cell is worse (model doesn’t know the grid contract).

Good cost. Risky quality. Needs a slice spec + a visual QA gate.

C

One call per item

N items → N API calls (batch n≤9). Closest to TVSN’s 100 PNGs. Cost and latency scale linearly. Needs a budget cap in the art stage (same idea as T2 max_t2_iterations).

Do not do this in v1 unless you want a 100-image shop as the acceptance bar.
