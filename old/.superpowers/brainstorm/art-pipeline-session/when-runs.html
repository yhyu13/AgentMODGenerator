When does the art stage run?

Sheet layout is LLM-emitted. It needs to know how many item cells exist. That list comes from the logic generators. Click one.

A

After logic, before T1 (recommended)

Route → logic generators (item pool, TV, mail, …) → art stage (grid spec → MiniMax → slice → PNG bytes + EditImage patches) → T1 → T2 → zip.

ArtSpec is built from prior_outputs. T1 can check PNG dimensions, palette size, and that every EditImage FromFile exists. One extra node on the existing LangGraph.

B

Inside the existing sprite/UI generators

No new graph node. ItemSpritesGenerator / UIAssetsGenerator call the art pipeline as a library. Same execution_order as today.

Less plumbing. Art is hidden inside two generators, so T1 never sees a first-class art stage. Harder to share across phases (texture later).

C

Parallel with logic

Art starts from the user prompt alone, same time as logic. Faster wall-clock. Grid cannot use the real item list — it guesses names. Slices and shop TSV drift.

Reject for v1. You already chose LLM-emitted grid; that grid must see logic output.
