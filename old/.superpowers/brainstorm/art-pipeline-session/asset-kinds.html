A — Sprites + UI only (recommended)

Item icons, channel icon, letter background, catalog tile. Closes the TVSN art gap. Maps stay JSON coordinates. MiniMax generates a large image; we crop/quantize to the slot.

B — A + sheet replacements

Also patch existing SDV sheets via EditImage (springobjects, etc.). Needs source-rect knowledge and palette match. Texture phase becomes real.

C — A + maps

Image models cannot emit .tbin / tilemaps. A “map image” is a painting, not a playable map. This is a different pipeline (tilesheet + TMX). Defer.

Why this question exists

MiniMax image-01 minimum size is 512×512. SDV item icons are 16×16. The art pipeline is mostly spec + crop + quantize, not “ask the model for a 16px PNG”. Maps make that mismatch worse, not better.
