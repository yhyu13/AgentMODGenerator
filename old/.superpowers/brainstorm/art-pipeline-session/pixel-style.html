A — Keep model pixels

Resize only. Looks like a photo sticker in a pixel game. Fastest. Fine for letter backgrounds / catalog chrome; bad for 16×16 item cells.

B — Quantize + nearest-neighbor (recommended)

Downscale to slot size, snap to a small palette (SDV-like 32–48 colors), 1-bit or keyed transparency. Deterministic. No second model. Cells look like sprites, not photos.

Use MiniMax image-01-live 漫画 style, or a pixel-art LoRA later. Best look if it works. Extra provider, extra latency, extra failure. Not v1 unless you want to bet the pipeline on style transfer.

Per-slot mix is allowed

Letter backgrounds can stay A (photo-ish). Item cells should be B. The pipeline can pick a post-process per ArtSpec.kind — the question is the default for sprite cells.
